# Fuentes del logo de SK Admin

- `engranaje-llave-original.svg`: trazado vectorial original exportado de Blender como Grease Pencil. Conserva el corte del engranaje y la forma de la llave.
- `circulo-original.svg`: trazado vectorial original del círculo, exportado por separado desde Blender.
- [`../../icons/icon-512.png`](../../icons/icon-512.png): composición final suministrada por el autor, con posición, escala, colores y transparencia aprobados. Es la referencia visual para cualquier trabajo futuro.

Los dos SVG se guardan **sin modificaciones** y tienen relleno negro porque así fueron exportados. El escalado, la alineación y los colores finales se aplicaron posteriormente en Photoshop; no están codificados en los SVG individuales. No se debe reemplazar el icono publicado por uno de esos SVG sin comparar la composición con `icons/icon-512.png`.
