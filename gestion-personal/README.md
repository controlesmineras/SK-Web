# GESTIÓN DE PERSONAL

Interfaz independiente de gestión de personal de Seguridad Física, publicada en GitHub Pages. Personal, servicios, permisos, disponibilidad y horas laboradas. El código fuente está en `source/`.

Abre el enlace privado entregado por el administrador. No se requiere iniciar sesión con ChatGPT. Las personas y movimientos se guardan en un servidor independiente; no se almacenan en este repositorio público.
