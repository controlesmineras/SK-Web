Política de Privacidad de SK Web

Última actualización: 8 de septiembre de 2026

SK Web es una aplicación de inventario y control de activos. Esta política explica cómo la aplicación utiliza la información necesaria para prestar sus funciones de almacenamiento, sincronización y operación sin conexión.

Acceso a Google

SK Web puede solicitar al usuario autorización mediante Google OAuth para utilizar Google Drive API. La aplicación utiliza el espacio privado de datos de aplicación de Google Drive (appDataFolder) exclusivamente para almacenar y sincronizar los datos propios de SK Web asociados a la cuenta de Google autorizada.

Datos tratados

La aplicación puede almacenar datos operativos introducidos por sus usuarios, tales como registros de inventario, activos, novedades, consumos, catálogos y datos necesarios para identificar responsables de registros. Una copia local puede mantenerse en el dispositivo para permitir funcionamiento sin conexión y mejorar el rendimiento.

Uso y compartición de los datos

Los datos obtenidos mediante las APIs de Google se utilizan únicamente para proporcionar las funciones de almacenamiento y sincronización solicitadas por el usuario. SK Web no vende los datos de los usuarios ni los utiliza con fines publicitarios. La aplicación no comparte con terceros los datos obtenidos mediante Google Drive API, salvo cuando sea necesario por obligación legal.

Almacenamiento y seguridad

Los datos sincronizados mediante Google Drive se almacenan en el espacio privado de datos de aplicación de la cuenta autorizada. La aplicación también puede conservar información localmente en el navegador del dispositivo. Se aplican medidas razonables para limitar el acceso a la información a las funciones y usuarios autorizados.

Control del usuario

El usuario puede retirar el acceso concedido a SK Web desde la configuración de seguridad de su cuenta de Google. Al retirar el acceso, SK Web dejará de poder sincronizar con el espacio de datos de aplicación de esa cuenta. Los datos locales existentes en un dispositivo pueden permanecer hasta que se eliminen desde dicho dispositivo o desde las funciones que la aplicación disponga para ello.

Alcance de los permisos

SK Web solicita únicamente los permisos de Google necesarios para sus funciones. El acceso destinado al almacenamiento de la aplicación se limita al espacio appDataFolder y no está diseñado para leer los archivos personales visibles del usuario en Mi unidad.

Cambios a esta política

Esta política puede actualizarse cuando cambien las funciones de SK Web o sus mecanismos de almacenamiento y sincronización. La versión vigente estará publicada en esta misma dirección.
